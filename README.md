**PROJECT: SKYBOUND — THE LAST MIGRATION** is an original, deterministic neon bullet-heaven survival game. Defend the migration relay, collect magnetic resonance shards, draft evolving interceptor upgrades, survive the 60-second breach, and destroy the Helix-Null Dreadnought.

## Run it

Requires Node.js 22.18+ and desktop Chrome.

```sh
node serve.ts
```

Open `http://localhost:8080`. The game is fully offline: no remote assets, network requests, packages, or remote audio.

## Controls

- **WASD / Arrow keys** — move
- **Space** — Chrono-Dash / brief invulnerability
- **1 / 2 / 3** — select an evolution card
- **R** — restart
- **Auto-fire** — targets the nearest threat automatically

## Core loop

Survive the 60-second evacuation window while swarms escalate. Kills and pickups feed the resonance meter; each level opens a three-card Common / Rare / Legendary upgrade draft. The Dreadnought enters at 01:00. Destroy its core to secure the migration; losing all interceptor integrity ends the run.
